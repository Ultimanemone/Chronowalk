# Designing a 2.5D Puzzle Game in Unity Featuring a Time-loop Mechanic

## Project Description
The project focuses on developing a 2.5D puzzle game based on a time-loop mechanic using Unity. The player must navigate through a puzzle room in order to reach an objective within a limited number of moves. When the move limit is reached or the player is defeated, the room resets while a ghost of the player's previous attempt repeats their actions. The player can then cooperate with their past selves to activate switches, move objects, open doors, avoid hazards, and solve puzzles that cannot be completed in a single run.

The game will feature a variety of puzzle rooms that gradually introduce new mechanics and require the player to plan how each loop contributes to the final solution. Later levels can combine multiple ghosts, environmental hazards, movable objects, and hostile creatures to increase the challenge. A limited number of loops may also be used to encourage efficient planning, with a potential scoring system rewarding players for completing puzzles with fewer attempts or moves.

Phase 1 will focus on developing the core gameplay and a playable set of puzzle rooms, including the time-loop, player movement, interactions, room reset, and ghost replay mechanics. A level data system and basic level creation tool will also be developed to support the creation and testing of different puzzle layouts. Phase 2 will build on this foundation by expanding the puzzle mechanics, level progression, hazards, enemy interactions, scoring, and overall game presentation.

## Project Objectives
### PHASE 1 (CURRENT PHASE):
- Survey existing time-loop and replay-based puzzle mechanics 
- Design the game architecture and gameplay loop 
- Develop player movement and interaction systems 
- Develop room/state reset system 
- Develop player action recording system 
- Develop ghost action replay system 
- Implement basic environmental interactions 
- Implement loop and move limitations 
- Develop basic puzzle completion and scoring conditions 
- Create a playable prototype demonstrating the core mechanic
- Implement a system to record, save and load level data to help with level creation
- Integrate the systems into a playable prototype
- Produce a Game Design Document
### PHASE 2:
- Expand multi-ghost interaction 
- Develop advanced environmental puzzles 
- Implement movable objects and interactive mechanisms 
- Develop hostile creature/hazard systems 
- Implement scoring and loop-efficiency mechanics 
- Expand level progression and difficulty 
- Refine UI/UX and game feedback, as well as various visual effects
- Conduct gameplay testing and difficulty evaluation 
- Optimize and polish the final game 
- Evaluate limitations and possible future extensions
